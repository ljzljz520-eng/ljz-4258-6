# 离线记事实与在线授权边界

## 离线事实

离线事实回答“谁/哪台设备在什么时候观察到什么”。它不授予业务状态。

- 设备读数是不可变事实，以 `(sourceId, seq)` 幂等；
- 时钟锚点记录设备时钟和参考时钟偏差，不直接篡改历史读数；
- 人工确认需要在线预授权票券和签名；
- observedAt 表示业务观察时间；receivedAt 表示服务器接收时间；
- 晚到数据允许补齐水位，但重复序号不能覆盖原值。

## 在线授权

在线授权回答“这些事实是否足以允许状态转移”。服务端独占以下决定：

- 身份真实且未禁用；
- 票券有效、未撤销、未过期且属于命令账号；
- 两名确认人账号不同；
- 两人资格包含 operator 与 quality；
- 两人绑定同一 `cultureId`、同一菌种版本、同一批次计划版本；
- 菌种 released、奶基 released、批次状态正确；
- `startSeq + minCount` 证据窗口内的连续来源序号达到要求；
- 不存在 open reconciliation；
- 只有通过所有规则才签发 `inoculation.issued`。

## 冲突

冲突不是错误弹窗后消失，而是可审计事实：

1. 保存离线证据；
2. 打开待协调项；
3. 阻止后续授权；
4. UI 显示具体原因；
5. 主管复核接受或要求重录；
6. 事件流保留全部过程。

## 非自动化承诺

系统不计算、推荐或下发接种量；不启动、停止或调节冷却。它只显示记录、计算证据水位、解释阻断并执行审计状态机。
